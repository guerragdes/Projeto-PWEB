# SOBRE

Este repositório contém um projeto de e-commerce desenvolvido com Spring MVC para a disciplina de Programação para Web II, do curso de Sistemas para Internet do Instituto Federal do Tocantins.

O objetivo do projeto é aplicar conceitos de desenvolvimento web utilizando Java, Spring Framework, arquitetura MVC e integração entre front-end e back-end.

O sistema permanece em desenvolvimento contínuo, com atualizações frequentes e expansão gradual de funcionalidades.
